#### 컬럼 구조 통일

매매 데이터에는 기존에 존재하지 않던 다음 컬럼을 추가하였다.

```text
아파트       → 매매

연립다세대   → 매매
전세         → 전세
월세         → 월세
```

#### 주택유형 통일

```text
단독 + 다가구 → 단독다가구
연립 + 다세대 → 연립다세대
```

### Page 2. 상관분석

목적:

지하철 이용량과 평균 부동산 가격 사이의 관계를 확인한다.

### Page 3. 역세권 유형 4분면

지하철 이용량과 부동산 가격을 기준으로 역세권 특성을 유형화한다.

```text
교통허브·고가
```

주요 시각화:

- 역별 위치
- 유형별 역 분포
- 연도·주택유형·거래유형별 결과 비교

### Page 4. 변화 분석

- 2022년 → 2025년 부동산 가격 변화율
- 이용량 변화율 ↔ 가격 변화율 산점도
- 역별 변화율 비교

※ 2026년은 부분 연도 데이터이므로 장기 변화율 비교에서 제외한다.
