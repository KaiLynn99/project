### 8/20 — 부동산 통합 데이터 구축

아래 6개 데이터를 하나의 분석용 데이터로 통합하였다.

1. 아파트
2. 오피스텔
3. 단독다가구
4. 연립다세대
5. 전세
6. 월세

#### 컬럼 구조 통일

매매 데이터에는 기존에 존재하지 않던 다음 컬럼을 추가하였다.

* `거래유형`
* `보증금`
* `임대료`

매매 데이터의 `보증금`, `임대료`는 해당 값이 존재하지 않으므로 `NULL`로 처리하였다.

#### 거래유형 통일

```text
아파트       → 매매
오피스텔     → 매매
단독다가구   → 매매
연립다세대   → 매매
전세         → 전세
월세         → 월세
```

#### 주택유형 통일

```text
단독 + 다가구 → 단독다가구
연립 + 다세대 → 연립다세대
```

#### 분석용 주요 컬럼

| 컬럼명  | 설명                   |
| ---- | -------------------- |
| 역명   | 분석 대상 지하철역           |
| 계약연월 | 부동산 계약 연·월           |
| 보증금  | 전·월세 보증금             |
| 임대료  | 월세 임대료               |
| 주택유형 | 아파트·오피스텔·단독다가구·연립다세대 |
| 거래유형 | 매매·전세·월세             |
