# 📊 第1次チームプロジェクト｜ソウル地下鉄2号線の利用者数と駅周辺の不動産分析

## 📌 1. プロジェクト概要

K-MOVEの第1次チームプロジェクトとして、**ソウル地下鉄2号線の駅別利用者数と駅周辺の不動産価格にどのような関係があるのか**を分析しました。

| 項目 | 内容 |
|---|---|
| 分析対象 | ソウル地下鉄2号線の33駅（変化率の比較では32駅） |
| 主な比較期間 | 2022～2025年 |
| 不動産の種類 | マンション、連立・集合住宅、戸建て・多世帯住宅、オフィステル |
| 取引の種類 | 売買、チョンセ（保証金型賃貸）、ウォルセ（月額賃貸） |
| 使用技術 | Python、Pandas、MySQL、SQL、Power BI |

## 🎯 2. 分析の目的

「**地下鉄の利用者数が多い駅ほど、周辺の不動産価格も高いのか？**」という疑問を出発点に、駅別の利用者数・平均取引価格・年ごとの変化を比較しました。

データはソウル市の公共交通関連公開データや韓国国土交通部の不動産取引データを使用しました。

## 🛠 3. 主な作業内容

- **データの前処理：** Python・Pandasで年度・駅名・住宅種類・取引種類を整理
- **データの統合：** MySQLの`JOIN`や`GROUP BY`で乗降客数と不動産取引データを集計
- **比較分析：** 駅別・年度別の利用者数と価格の推移、相関関係を確認
- **駅の分類：** 利用者数と価格を基準とする4象限分析
- **可視化：** Power BIで傾向を確認できるダッシュボードを作成

## 📈 4. 分析からわかったこと

2022年から2025年までの変化率を比較した32駅の分析では、地下鉄利用者数の変化率と不動産価格の変化率の相関係数は**約 -0.185**でした（当時のPower BI分析記録に基づく値）。

この結果だけでは、地下鉄利用者数の増加が不動産価格の上昇につながるとはいえません。**相関関係と因果関係を区別して考える重要性**を学びました。
