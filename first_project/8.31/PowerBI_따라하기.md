# 2호선 역세권 대시보드 — Power BI 따라하기

HTML 대시보드에 있던 4개 화면(현황 / 상관분석 / 역 유형 4분면 / 변화 분석)을
Power BI에서 그대로 만드는 과정입니다. 순서대로 따라가면 됩니다.

---

## 0장. 먼저 알아둘 것

### 0-1. 왜 파일을 새로 만들어 드렸나

올려주신 CSV 4개를 그대로 써도 되지만, 두 가지 걸림돌이 있습니다.

1. **인코딩** — 올려주신 파일은 `CP949(한글 윈도우 전용)` 로 저장돼 있습니다.
   Power BI가 이걸 자동으로 못 알아채면 역명이 `媛뺣궓` 처럼 다 깨집니다.
2. **컬럼 이름이 영어** — `station_name`, `transaction_amount` 같은 이름이
   화면에 그대로 나옵니다.

그래서 **UTF-8(BOM 포함) + 한글 컬럼명**으로 바꾼 파일을 함께 드립니다.
이제 더블클릭만 하면 안 깨집니다.

### 0-2. 쓸 파일 4개

| 파일 | 행 수 | 컬럼 | 역할 |
|---|---|---|---|
| `부동산.csv` | 802,751 | 역명, 연도, 주택유형, 거래유형, 거래금액, 보증금, 임대료, **대표금액** | 거래 하나가 한 줄 (팩트) |
| `지하철연간.csv` | 165 | 연도, 역명, 총승차, 총하차, 총이용량 | 연도×역 이용량 (팩트) |
| `역마스터.csv` | 33 | 역명, 노선순서 | 역 이름표 (차원) |
| `연도.csv` | 5 | 연도, 분석포함 | 연도 이름표 (차원) |

> **`대표금액`이 뭔가요?**
> 거래유형마다 "가격"에 해당하는 칸이 다릅니다.
> 매매는 거래금액, 전세는 보증금, 월세는 임대료(월세액)죠.
> 매번 나눠 계산하면 복잡해서, **거래유형에 맞는 금액을 미리 한 칸에 모아둔 컬럼**입니다.
> 이게 있으면 평균가격 계산이 `AVERAGE(대표금액)` 한 줄로 끝납니다.

> **안 쓰는 파일 2개**
> `subway_final.csv` 는 일별 데이터인데 날짜 컬럼이 없어서(연도만 있음) 일별로 쪼갤 수가 없습니다.
> 연도별 합계는 `station_annual.csv` 가 이미 갖고 있으니 그걸 쓰면 됩니다.
> `station_analysis.csv` 는 매매만 미리 집계된 표라 전세·월세를 못 봅니다.
> 원본(`부동산.csv`)에서 직접 계산하는 게 낫습니다.

### 0-3. 완성하면 이렇게 됩니다

- 위쪽에 **슬라이서 3개** — 연도 / 주택유형 / 거래유형
- 아래에 **페이지 4개** — 현황, 상관분석, 4분면, 변화 분석
- 슬라이서를 바꾸면 모든 숫자와 그래프가 같이 바뀜

## 2장. 데이터 불러오기

### 2-1. 4개 파일 한 번에 넣기

1. 위쪽 리본에서 **홈 → 데이터 가져오기 → 텍스트/CSV**
2. `부동산.csv` 선택 → **열기**
3. 미리보기 창이 뜹니다. 여기서 확인할 것 두 가지:
   - **파일 원본** 이 `65001: 유니코드(UTF-8)` 인지 → 아니면 드롭다운에서 바꾸기
   - 역명이 한글로 제대로 보이는지
4. 오른쪽 아래 **로드** 클릭. (변환은 나중에)
5. 같은 방법으로 `지하철연간.csv`, `역마스터.csv`, `연도.csv` 도 각각 불러옵니다.

> 부동산.csv는 80만 행이라 불러오는 데 30초~2분 걸립니다. 정상입니다.

### 2-2. 제대로 들어왔는지 확인

왼쪽 세로 아이콘 중 **표 모양(데이터 보기)** 을 누르면 오른쪽에 테이블 4개가 보여야 합니다.

- 부동산
- 지하철연간
- 역마스터
- 연도

각각 눌러서 한글이 안 깨졌는지, 행 수가 맞는지(화면 아래에 표시됨) 봅니다.

### 2-3. 자료 형식 손보기

**데이터 보기**에서 컬럼을 클릭하면 위 리본에 **열 도구**가 생깁니다. 여기서 형식을 맞춥니다.

| 테이블 | 컬럼 | 형식 |
|---|---|---|
| 부동산 | 역명, 주택유형, 거래유형 | 텍스트 |

| 부동산 | 거래금액, 보증금, 임대료, 대표금액 | 정수 |

대부분 자동으로 맞게 들어옵니다. **연도가 날짜로 잡혔다면 반드시 정수로 바꾸세요.**

### 2-4. 역명을 노선 순서대로 정렬시키기

이걸 안 하면 표나 슬라이서에서 역이 가나다순(강남, 건대입구, 교대…)으로 나옵니다.
2호선 순서(시청 → 신당 → 상왕십리 …)로 나오게 하려면:

## 3장. 데이터 모델(관계) 만들기

### 3-1. 왜 필요한가

지금은 테이블 4개가 서로 남남입니다.
"2025년 강남" 이라고 조건을 걸면 부동산 테이블과 지하철 테이블이 **동시에** 걸러져야 하는데,
연결이 없으면 각자 놀아버립니다.

그래서 **역마스터**와 **연도**를 가운데 두고, 나머지 두 팩트 테이블을 매답니다.

```
            [연도]
           ↙      ↘
    [부동산]      [지하철연간]
           ↖      ↗
          [역마스터]
```

### 3-2. 관계 4개 만들기

1. 왼쪽 세로 아이콘 중 **모델 보기(연결선 모양)** 클릭
2. 테이블 상자를 드래그해서 위 그림처럼 배치 (보기 편하려고 하는 것뿐)
3. 아래 4개를 만듭니다. **끄는 방향이 중요합니다 — 항상 "이름표 테이블 → 데이터 테이블" 방향으로 끕니다.**

| 끄는 곳 (1쪽) | 놓는 곳 (다수쪽) |
|---|---|
| 역마스터[역명] | 부동산[역명] |
| 역마스터[역명] | 지하철연간[역명] |
| 연도[연도] | 부동산[연도] |
| 연도[연도] | 지하철연간[연도] |

4. 만들어진 선을 **더블클릭**해서 확인:
   - 카디널리티: **일대다(1:*)**
   - 크로스 필터 방향: **단일**
   - "이 관계 활성화" 체크됨

> 화살표가 반대(부동산 → 역마스터)로 잡혔으면 선을 지우고 다시 끄세요.
> 선 위에서 우클릭 → 삭제.

### 3-3. 이름표 테이블 숨기기 정리

`부동산` 테이블의 `역명`, `연도` 컬럼은 이제 직접 쓸 일이 없습니다.
(역마스터/연도 것을 씁니다.) 헷갈리지 않게 숨겨두면 좋습니다.

- `부동산 > 연도`, `지하철연간 > 역명`, `지하철연간 > 연도` 도 동일하게

## 4장. 측정값(DAX) 만들기

여기가 제일 중요합니다. 천천히 하세요.

### 4-1. 측정값이 뭔가

컬럼은 "이미 저장된 값"이고, 측정값은 "지금 화면 조건에 맞춰 그때그때 계산하는 값"입니다.
`2025년 + 아파트 + 매매` 를 고르면 평균가격이 그 조건으로 다시 계산됩니다.

### 4-2. 측정값 전용 테이블 만들기

측정값이 20개가 넘어가면 어디 있는지 못 찾습니다. 전용 서랍을 하나 만듭니다.

1. **홈 → 데이터 입력**
2. 테이블 이름에 `_측정값` 입력 → **로드**
3. 오른쪽 데이터 창에 `_측정값` 테이블이 생깁니다. 안의 `Column1` 은 우클릭 → 삭제.

앞으로 측정값을 만들 땐 **항상 `_측정값` 테이블을 먼저 클릭**한 뒤 만드세요.

### 4-3. 만드는 방법

1. 오른쪽 데이터 창에서 `_측정값` 클릭
2. 리본 **테이블 도구 → 새 측정값**
3. 위에 수식 입력줄이 뜹니다. 아래 코드를 **통째로 복사해서 붙여넣기**
4. **Enter** 또는 체크(✓) 클릭

수식 줄에서 줄바꿈은 `Shift + Enter` 입니다. 그냥 Enter는 저장입니다.

### 4-4. 기본 측정값 (5개)

거래건수 = COUNTROWS('부동산')

평균가격 = AVERAGE('부동산'[대표금액])

- `평균가격` → 형식 **정수**, 쉼표 켜기

### 4-5. 1페이지(현황)용 측정값 (6개)

```dax
대상 역 수 = DISTINCTCOUNT('부동산'[역명])
```
선택한 조건에서 실제로 거래가 있었던 역이 몇 개인지.

```dax
전체 평균가격 = AVERAGEX( VALUES('역마스터'[역명]), [평균가격] )
```
"역별 평균의 평균"입니다. 거래 건수가 많은 역에 끌려가지 않게 하려는 계산입니다.

```dax
역별 이용량 =
IF( NOT ISBLANK([평균가격]), [총이용량] )
```
거래가 없는 역은 막대에서 빼기 위한 장치입니다.
(예: 당산·신대방·잠실은 전세/월세 거래가 아예 없습니다.)

```dax
이용량 1위 역 =
VAR 후보 = FILTER( VALUES('역마스터'[역명]), NOT ISBLANK([평균가격]) )
VAR 최상위 = TOPN( 1, 후보, [총이용량], DESC )
RETURN CONCATENATEX( 최상위, '역마스터'[역명], ", " )
```

```dax
이용량 1위 값 =
MAXX( FILTER( VALUES('역마스터'[역명]), NOT ISBLANK([평균가격]) ), [총이용량] )
```

```dax
가격 1위 역 =
VAR 후보 = FILTER( VALUES('역마스터'[역명]), NOT ISBLANK([평균가격]) )
VAR 최상위 = TOPN( 1, 후보, [평균가격], DESC )
RETURN CONCATENATEX( 최상위, '역마스터'[역명], ", " )
```

```dax
가격 1위 값 =
MAXX( FILTER( VALUES('역마스터'[역명]), NOT ISBLANK([평균가격]) ), [평균가격] )
```

**코드 읽는 법 (이용량 1위 역 기준)**
- `VALUES('역마스터'[역명])` — 지금 화면에 걸린 조건에서 살아있는 역 목록
- `FILTER(..., NOT ISBLANK([평균가격]))` — 그중 거래가 있는 역만 남김
- `TOPN(1, 후보, [총이용량], DESC)` — 이용량 큰 순으로 1등 하나
- `CONCATENATEX(...)` — 그 1등의 이름을 글자로 꺼냄 (동점이면 쉼표로 나열)

### 4-6. 2페이지(상관분석)용 측정값 (4개)

```dax
표본수 = COUNTROWS( FILTER( VALUES('역마스터'[역명]), NOT ISBLANK([평균가격]) ) )
```

```dax
상관계수 =
VAR 표 =
    FILTER(
        ADDCOLUMNS(
            VALUES('역마스터'[역명]),
            "@이용량", [총이용량],
            "@가격",   [평균가격]
        ),
        NOT ISBLANK( [@가격] )
    )
VAR n      = COUNTROWS( 표 )
VAR 평균U  = AVERAGEX( 표, [@이용량] )
VAR 평균P  = AVERAGEX( 표, [@가격] )
VAR 공분산 = SUMX( 표, ( [@이용량] - 평균U ) * ( [@가격] - 평균P ) )
VAR 편차U  = SQRT( SUMX( 표, ( [@이용량] - 평균U ) ^ 2 ) )
VAR 편차P  = SQRT( SUMX( 표, ( [@가격]   - 평균P ) ^ 2 ) )
RETURN
    IF( n >= 3, DIVIDE( 공분산, 편차U * 편차P ) )
```

**이게 하는 일**
1. 역 하나당 (이용량, 평균가격) 짝을 만든 임시 표를 만듭니다.
2. 각각의 평균을 구합니다.
3. 피어슨 상관계수 공식 `Σ(x-x̄)(y-ȳ) ÷ √Σ(x-x̄)² · √Σ(y-ȳ)²` 을 그대로 계산합니다.

결과는 -1 ~ +1. 1에 가까울수록 "이용량 많은 역이 비싸다"가 강한 것.

```dax
임계값 =
VAR n = [표본수]
RETURN IF( n > 2, DIVIDE( 2.05, SQRT( n - 2 + 2.05 ^ 2 ) ) )
```
표본이 n개일 때, 유의수준 5%에서 "우연이 아니다"라고 말하려면 넘어야 하는 상관계수 값입니다.
역이 32개면 약 0.351이 나옵니다.

```dax
임계값 음수 = -[임계값]
```
그래프에 아래쪽 점선을 그리려고 만듭니다.

```dax
유의성 판정 =
VAR r = [상관계수]
VAR c = [임계값]
RETURN
    IF( ISBLANK(r), "—",
        IF( ABS(r) >= c, "유의 (관계 인정)", "유의하지 않음" ) )
```

서식: `상관계수`, `임계값` → **10진수, 소수 자릿수 3**

### 4-7. 3페이지(4분면)용 측정값 (8개)

표준점수(z-score)는 "평균에서 표준편차 몇 개만큼 떨어져 있나"입니다.
이용량과 가격은 단위가 완전히 다르니(명 vs 만원) 둘 다 표준점수로 바꿔야 같은 그래프에 놓을 수 있습니다.

```dax
Z이용량 =
VAR 표 =
    FILTER(
        ADDCOLUMNS(
            ALL('역마스터'[역명]),
            "@이용량", [총이용량],
            "@가격",   [평균가격]
        ),
        NOT ISBLANK( [@가격] )
    )
VAR n     = COUNTROWS( 표 )
VAR 평균U = AVERAGEX( 표, [@이용량] )
VAR 표준U = SQRT( DIVIDE( SUMX( 표, ( [@이용량] - 평균U ) ^ 2 ), n - 1 ) )
RETURN
    IF( NOT ISBLANK([평균가격]), DIVIDE( [총이용량] - 평균U, 표준U ) )
```

```dax
Z가격 =
VAR 표 =
    FILTER(
        ADDCOLUMNS( ALL('역마스터'[역명]), "@가격", [평균가격] ),
        NOT ISBLANK( [@가격] )
    )
VAR n     = COUNTROWS( 표 )
VAR 평균P = AVERAGEX( 표, [@가격] )
VAR 표준P = SQRT( DIVIDE( SUMX( 표, ( [@가격] - 평균P ) ^ 2 ), n - 1 ) )
RETURN
    DIVIDE( [평균가격] - 평균P, 표준P )
```

> `ALL('역마스터'[역명])` 을 쓴 이유: 평균과 표준편차는 **33개 역 전체 기준**으로 고정돼야 합니다.
> 그냥 두면 그래프의 점 하나(=역 하나)만 놓고 평균을 내버려서 항상 0이 나옵니다.

```dax
역 유형 =
VAR u = [Z이용량]
VAR p = [Z가격]
RETURN
    IF( ISBLANK(u) || ISBLANK(p), BLANK(),
        IF( u > 0,
            IF( p > 0, "교통허브·고가", "교통허브·중저가" ),
            IF( p > 0, "주거중심·고가", "주거중심·중저가" ) ) )
```

```dax
격차 = [Z가격] - [Z이용량]
```
양수면 "사람 다니는 것에 비해 비싼 역", 음수면 "저평가된 역".

```dax
역 유형 색 =
SWITCH( [역 유형],
    "교통허브·고가",   "#00A84D",
    "교통허브·중저가", "#E4572E",
    "주거중심·고가",   "#2D6BB5",
    "주거중심·중저가", "#A8AC9E",
    "#DFE2D8" )
```

사분면별 역 개수 4개:

```dax
교통허브 고가 수 = COUNTROWS( FILTER( ALL('역마스터'[역명]), [역 유형] = "교통허브·고가" ) )
```
```dax
교통허브 중저가 수 = COUNTROWS( FILTER( ALL('역마스터'[역명]), [역 유형] = "교통허브·중저가" ) )
```
```dax
주거중심 고가 수 = COUNTROWS( FILTER( ALL('역마스터'[역명]), [역 유형] = "주거중심·고가" ) )
```
```dax
주거중심 중저가 수 = COUNTROWS( FILTER( ALL('역마스터'[역명]), [역 유형] = "주거중심·중저가" ) )
```

서식: `Z이용량`, `Z가격`, `격차` → **10진수, 소수 2자리**

### 4-8. 4페이지(변화 분석)용 측정값 (8개)

2022년과 2025년만 비교합니다. 2026년은 8월까지만 있는 반쪽 데이터라 뺍니다.

```dax
이용량 2022 = CALCULATE( [총이용량], REMOVEFILTERS('연도'), '연도'[연도] = 2022 )
```
```dax
이용량 2025 = CALCULATE( [총이용량], REMOVEFILTERS('연도'), '연도'[연도] = 2025 )
```
```dax
가격 2022 = CALCULATE( [평균가격], REMOVEFILTERS('연도'), '연도'[연도] = 2022 )
```
```dax
가격 2025 = CALCULATE( [평균가격], REMOVEFILTERS('연도'), '연도'[연도] = 2025 )
```

> `REMOVEFILTERS('연도')` — 화면의 연도 슬라이서를 **무시**하고, 그 자리에 2022(또는 2025)를 강제로 끼워 넣습니다.
> 이게 없으면 슬라이서에서 2024를 고른 순간 "2024이면서 2022"인 조건이 돼서 값이 텅 빕니다.

```dax
가격 변화율 =
VAR a = [가격 2022]
VAR b = [가격 2025]
RETURN IF( NOT ISBLANK(a) && NOT ISBLANK(b), DIVIDE( b - a, a ) )
```

```dax
이용량 변화율 =
VAR a = [이용량 2022]
VAR b = [이용량 2025]
RETURN IF( NOT ISBLANK([가격 2022]) && NOT ISBLANK([가격 2025]), DIVIDE( b - a, a ) )
```
> 이용량은 33개 역 모두 있지만, **가격이 양쪽 다 있는 역만** 비교 대상으로 잡습니다.
> 그래야 산점도의 x·y 짝이 맞습니다.

```dax
변화 비교 역 수 = COUNTROWS( FILTER( ALL('역마스터'[역명]), NOT ISBLANK([가격 변화율]) ) )
```
```dax
이용량 변화율 중앙값 = MEDIANX( FILTER( ALL('역마스터'[역명]), NOT ISBLANK([가격 변화율]) ), [이용량 변화율] )
```
```dax
가격 변화율 중앙값 = MEDIANX( FILTER( ALL('역마스터'[역명]), NOT ISBLANK([가격 변화율]) ), [가격 변화율] )
```

```dax
변화율 상관 =
VAR 표 =
    FILTER(
        ADDCOLUMNS(
            ALL('역마스터'[역명]),
            "@U", [이용량 변화율],
            "@P", [가격 변화율]
        ),
        NOT ISBLANK( [@P] )
    )
VAR n      = COUNTROWS( 표 )
VAR 평균U  = AVERAGEX( 표, [@U] )
VAR 평균P  = AVERAGEX( 표, [@P] )
VAR 공분산 = SUMX( 표, ( [@U] - 평균U ) * ( [@P] - 평균P ) )
VAR 편차U  = SQRT( SUMX( 표, ( [@U] - 평균U ) ^ 2 ) )
VAR 편차P  = SQRT( SUMX( 표, ( [@P] - 평균P ) ^ 2 ) )
RETURN
    IF( n >= 3, DIVIDE( 공분산, 편차U * 편차P ) )
```

서식:
- `가격 변화율`, `이용량 변화율`, `~중앙값` → **백분율, 소수 1자리**
  (DIVIDE 결과가 0.298 이니 서식만 %로 바꾸면 29.8%로 보입니다)
- `변화율 상관` → 10진수 3자리

## 9장. 4페이지 — 변화 분석

`변화율 상관` / `이용량 변화율 중앙값` / `가격 변화율 중앙값` / `변화 비교 역 수`

### 9-2. 산점도: 변화율 vs 변화율

1. **분산형 차트**
2. **값**: `역마스터 > 역명`
3. **X축**: `이용량 변화율`
4. **Y축**: `가격 변화율`
5. X·Y축 제목: `지하철 이용량 변화율 (%)`, `가격 변화율 (%)`
6. 표식 색 주황(#E4572E)
7. 분석 창에서 X축·Y축 상수 선 `0` 추가 (증가/감소 경계)

### 9-3. 묶은 막대: 역별 변화율

1. **묶은 가로 막대형 차트**
2. **Y축**: `역마스터 > 역명`
3. **X축**: `이용량 변화율` 과 `가격 변화율` **둘 다** 넣기
4. **… → 축 정렬 → 이용량 변화율 → 내림차순**
5. 서식 → **범례** 켜기, 위치 위쪽
6. 색: 이용량 초록, 가격 파랑

### 9-4. 설명 텍스트 넣기

**삽입 → 텍스트 상자** 로 아래 문장을 넣어두면 발표 때 편합니다.

> 2022년과 2025년을 비교했다. 2026년은 8월까지만 집계된 부분 연도라 변화율 계산에서 제외했다.

## 12장. 자주 나는 문제

**역명이 `媛뺣궓` 처럼 깨져요**
드린 UTF-8 파일이 아니라 원본 CSV를 불러온 것입니다.
Power Query 편집기 → 오른쪽 "적용된 단계"의 **원본** 클릭 → 톱니 → 파일 원본을 `65001: 유니코드(UTF-8)` 로.

**모든 역의 값이 똑같이 나와요**
관계가 안 걸린 것입니다. 모델 보기에서 선 4개가 다 있는지, 방향이 `역마스터 → 부동산` 인지 확인하세요.

**Z이용량이 전부 0이에요**
`ALL('역마스터'[역명])` 을 빼먹었거나 `VALUES` 로 썼을 가능성이 큽니다.
평균을 33개 역 전체에서 내야 하는데 점 하나만 놓고 평균을 내면 자기 자신이 평균이라 0이 됩니다.

**변화 분석 값이 전부 비어 있어요**
`REMOVEFILTERS('연도')` 가 빠졌습니다. 슬라이서 연도와 고정 연도(2022)가 충돌해서 빈 값이 됩니다.

**측정값 이름이 안 잡혀요 (빨간 밑줄)**
DAX는 대괄호 안 이름이 정확히 일치해야 합니다. 띄어쓰기까지 같아야 합니다.
`[전체 평균가격]` 과 `[전체평균가격]` 은 다른 이름입니다.

**너무 느려요**
80만 행이라 첫 렌더링에 몇 초 걸릴 수 있습니다.
심하면 `부동산` 테이블에서 `거래금액`, `보증금`, `임대료` 컬럼을 Power Query에서 삭제하세요
(`대표금액`만 있으면 대시보드는 다 돌아갑니다). 파일 크기가 절반 이하로 줍니다.

**막대에 33개 역이 다 안 나와요**
정상입니다. 당산·신대방·잠실은 전세/월세 거래 자체가 없어서 그 조건에서는 빠집니다.
`대상 역 수` 카드가 그래서 30~33 사이를 오갑니다.
