### 8/20 — 부동산 통합 데이터 구축

아래 6개 데이터를 하나의 분석용 데이터로 통합하였다.

1. 아파트
2. 오피스텔
3. 단독다가구
4. 연립다세대
5. 전세
6. 월세

#### 컬럼 구조 통일

매매 데이터에는 기존에 존재하지 않던 다음 컬럼을 추가하였다.

* `거래유형`
* `보증금`
* `임대료`

매매 데이터의 `보증금`, `임대료`는 해당 값이 존재하지 않으므로 `NULL`로 처리하였다.

#### 거래유형 통일

```text
아파트       → 매매
오피스텔     → 매매
단독다가구   → 매매
연립다세대   → 매매
전세         → 전세
월세         → 월세
```

#### 주택유형 통일

```text
단독 + 다가구 → 단독다가구
연립 + 다세대 → 연립다세대
```

### 8/24 — 분석용 데이터 집계 및 Dashboard 설계

#### 분석용 집계 데이터 구성

부동산 상세 데이터와 지하철 이용량 데이터를 Power BI 및 통계 분석에 활용할 수 있도록 집계하였다.

주요 집계 기준:

```text
연도
역명
주택유형
거래유형
```

주요 분석 지표:

```text
거래건수
평균 부동산 가격
지하철 이용량
```

이를 통해 상세 거래 데이터를 그대로 사용하는 방식에서 벗어나, 역별·연도별·주택유형별·거래유형별 비교가 가능한 분석용 데이터 구조를 구성하였다.

#### Dashboard 분석 구조 설계

부동산·지하철 통합 데이터를 기반으로 Dashboard에서 확인할 핵심 분석 영역을 다음과 같이 구성하였다.

1. **현황 분석**

   * 역별 지하철 이용량 비교
   * 역별 평균 부동산 가격 비교
   * 거래건수 및 주요 KPI 확인

2. **상관관계 분석**

   * 지하철 이용량과 평균 부동산 가격의 산점도 구성
   * Pearson 상관계수를 활용한 관계 분석
   * 연도별 상관계수 변화 비교

3. **역세권 유형 분석**

   * 지하철 이용량과 부동산 가격을 표준화하여 비교
   * 평균 수준을 기준으로 역세권을 4개 유형으로 분류

```text
교통허브·고가
교통허브·중저가
주거중심·고가
주거중심·중저가
```

4. **변화 분석**

   * 2022년과 2025년의 지하철 이용량 변화율 비교
   * 2022년과 2025년의 부동산 가격 변화율 비교
   * 이용량 변화와 가격 변화 간 관계 분석
   * 2026년은 부분 연도 데이터이므로 장기 변화율 비교에서 제외

#### Dashboard 필터 설계

사용자가 조건을 변경하면서 분석 결과를 확인할 수 있도록 다음 필터 구조를 설정하였다.

* 연도
* 주택유형
* 거래유형

#### Power BI 시각화 작업

Dashboard 프로토타입을 참고하여 Power BI에서 실제 시각화 구현을 시작하였다.

현재 구성 및 구현 중인 항목:

* KPI 카드
* 연도 슬라이서
* 주택유형 슬라이서
* 거래유형 슬라이서
* 역별 지하철 이용량 막대차트
* 역별 평균 부동산 가격 막대차트
* 지하철 이용량과 부동산 가격 산점도
* Dashboard 전체 레이아웃 구성

#### 분석 시 주의사항

* 동일 역·연도의 지하철 이용량이 주택유형·거래유형별 행에 반복될 수 있으므로 단순 합계 사용 여부를 검토한다.
* 매매·전세·월세는 가격의 의미가 다르므로 거래유형을 구분하여 분석한다.
* 2026년 데이터는 부분 연도 데이터이므로 2022~2025년 연간 데이터와 직접적인 증감률 비교 시 주의한다.
* 상관관계 분석 결과는 Dashboard 시각화 결과만으로 확정하지 않고 계산 결과를 별도로 검증한다.
