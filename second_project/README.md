# 📊 第2次チームプロジェクト｜日本の電力市場（JEPX）の価格予測

## 📌 1. プロジェクト概要

本プロジェクトは、K-MOVEの「ビッグデータ分析に基づくAIアルゴリズム開発者養成課程」で取り組んでいる第2次チームプロジェクトです。

日本の電力市場（JEPX）の価格データを対象に、PythonやSQLを活用してデータの前処理・探索的データ分析（EDA）・価格予測・予測誤差の評価に取り組んでいます。

単に予測モデルを作成するだけでなく、データの特徴を理解し、分析結果が実際にどのような課題解決に役立つのかを考えることを重視しています。

**プロジェクト概要**

| 使用技術 | Python、Pandas、SQL、MySQL、Power BI |

## 🎯 2. プロジェクトの目的

本プロジェクトでは、以下の3点を目標としています。

1. **データの理解：** 電力価格データの構造や特徴を確認し、価格変動の傾向を把握する
2. **予測と評価：** 過去のデータを利用したベースライン予測を行い、実際の価格との差を評価する
3. **分析結果の活用：** 価格変動を理解することが、電力調達やリスク管理などにどのように役立つかを検討する

## 🛠 4. 分析の流れ

### ① データの確認・前処理

- データの構造や各列の意味を確認
- データの整理・変換
- 分析対象となるデータの整合性を確認
- SQLによるデータ処理・検証

**主なデータ：** `merged_30min.csv`

### ② 探索的データ分析（EDA）

電力価格の特徴を理解するため、以下のような分析・可視化に取り組んでいます。

- 時間帯別の平均価格
- 月別の平均価格
- 平日と休日の価格比較
- 予備率と電力価格の関係

SQLによる集計と可視化を組み合わせ、データの傾向を確認しています。

### ③ ベースライン予測

複雑な機械学習モデルを構築する前に、比較基準となるベースライン予測を評価しています。

| 項目 | 使用する列 |
|---|---|
| 実際の電力価格 | `y_price` |
| ベースライン予測値 | `price_tokyo_lag1d` |
| データ区分 | `split` |
| 評価指標 | MAE（平均絶対誤差） |

`split`が`valid`および`test`であるデータを対象に、実測値と予測値の誤差を評価します。

MAEは、予測値と実測値の差の絶対値を平均した指標です。値が小さいほど、予測誤差が小さいことを意味します。

### ④ SQLとPythonによる検証

データの処理や分析結果を確認するため、SQLとPythonを使用しています。

異なる方法で計算結果を比較することで、データ処理や評価結果に不整合がないかを確認することを目的としています。

## 📈 5. 分析結果・可視化

現時点では、電力価格の特徴を把握するための分析と、ベースライン予測の評価を進めています。

主な分析内容は次のとおりです。

| 分析内容 | 確認するポイント |
|---|---|
| 時間帯別平均価格 | 時間帯による価格の違い |
| 月別平均価格 | 月ごとの価格変動 |
| 平日・休日の比較 | 曜日による価格傾向 |
| 予備率と価格の比較 | 需給状況と価格の関係 |
| MAEによる予測評価 | 予測値と実測値の誤差 |

※ 最終的な予測精度の比較・考察は、分析結果を確認したうえで更新する予定です。
