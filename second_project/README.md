## 📌 プロジェクトテーマの変更について

本プロジェクトでは、当初、日本のアニメ作品の評価データを活用し、作品の特徴と評価の関係を分析することを検討していました。

そのため、基本的なデータ分析に加え、制作陣や声優などの情報に着目した探索的データ分析（EDA）に取り組みました。

しかし、分析の目的や回帰モデルによる予測の有用性について検討する中で、アニメの評価を予測するだけでは、実際の課題解決への活用方法を明確に示すことが難しいと考えました。

そこでチームでテーマを再検討し、**日本の電力市場（JEPX）の価格予測**に変更しました。

現在は、データの前処理、SQLを用いた検証、ベースライン予測の評価などに取り組んでいます。

なお、当初のアニメ分析に関するフォルダは削除せず、**テーマ選定から方針変更に至る検討過程を示す記録**として残しています。

この経験を通して、データ分析ではモデルを作成すること自体だけでなく、予測の目的や分析結果の活用方法を考えることも重要だと学びました。
