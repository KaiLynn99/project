# 📊 第2次チームプロジェクト｜JEPX電力価格予測・高騰リスク分析

## 📌 1. プロジェクト概要

韓国政府支援のIT研修（K-MOVE）における第2次チームプロジェクトとして、日本卸電力取引所（JEPX）の東京エリアの電力価格データを分析しています。

電力価格の変動傾向を把握し、機械学習を活用して翌日の価格高騰を予測することが目的です。

さらに、予測結果を電力調達の判断に活用することで、**仮想の小売電気事業者が調達コストをどの程度削減できるか**を検証しました。

| 項目 | 内容 |
|---|---|
| チーム名 | モダピ |
| 分析対象 | JEPX・東京エリアの卸電力価格 |
| 対象期間 | 2024年4月～2026年10月 |
| データ規模 | 45,312件（30分単位） |
| 使用技術 | Python、Pandas、SQL、MySQL、Power BI、機械学習 |
| 主な分析 | データ前処理、EDA、価格予測、高騰分類、バックテスト |
| 評価指標 | MAE、適合率、再現率、AP、想定削減額 |
| 進捗 | モデル比較・選定、バックテスト、ダッシュボード作成 |

## 🔄 2. テーマ変更の経緯

当初は日本のアニメ作品の評価データを用いて、作品の特徴や制作陣・声優と評価の関係を分析していました。

しかし、分析結果を実際の課題解決に結びつけることが難しいと考え、チームで検討した結果、**JEPXの電力価格予測**へテーマを変更しました。

新しいテーマでは、価格を予測するだけでなく、価格高騰に備えた意思決定への活用を目指しています。

初期のアニメ分析資料も、テーマ選定と変更の過程を示す記録として保存しています。

## 🛠 3. 主な分析内容

### ① データ前処理・SQL分析

- JEPXや電力需給などに関するデータを整理
- `merged_30min.csv`を用いたデータ構造の確認
- SQLによるデータの集計・検証
- 欠損値の処理や予測に利用する変数の検討
- 予測時点で利用可能な情報を考慮したデータ設計

### ② 探索的データ分析（EDA）・可視化

- 月別・時間帯別の電力価格の変動
- 平日と休日における価格高騰の傾向
- 電力需給や予備率と価格の関係
- Power BIやHTMLダッシュボードによる可視化

### ③ 価格予測・機械学習モデルの比較

まず、前日の同じ時間帯の価格を利用したベースライン予測を実施し、MAEで予測誤差を評価しました。

その後、価格高騰の有無を予測する分類問題にも取り組み、LightGBM、Random Forest、Extra Treesなど8種類のモデルを比較しました。

最終的には、検証期間における高騰の検知性能と想定調達コストの削減効果を比較し、**Extra Trees（エクストラツリー）**を採用しました。

最終構成では気象データを除外し、予測確率50%以上を警報の基準としています。

### ④ 予測結果を活用したバックテスト

電力価格が高騰する時間帯を事前に把握し、必要な時間帯に限って代替調達を行う戦略を検証しました。

単純なルールによる判断と、ルールに機械学習モデルを組み合わせた判断を比較し、コスト削減の可能性を分析しました。

## 📈 4. 主な分析結果

2025年11月～2026年10月のテスト期間において、最終的な高騰予測モデルは次の結果を示しました。

| 評価項目 | 結果 |
|---|---:|
| 実際の価格高騰 | 1,619件 |
| 検知した価格高騰 | 1,086件 |
| 再現率 | 67.1% |
| 適合率 | 39.9% |
| AP（平均適合率） | 0.492 |

また、仮想の小売電気事業者を対象としたバックテストでは、次の試算結果が得られました。

| 調達戦略 | 想定削減額 |
|---|---:|
| ルールのみ | 1億3,680万円 |
| ルール＋Extra Trees | 2億460万円 |
| モデル追加による差額 | ＋6,780万円 |

※ 東京エリア需要の0.1%を調達する仮想事業者を想定し、代替調達単価を直近30日平均の1.2倍とした場合の試算です。実際の事業者で削減できた金額ではありません。

一方、価格そのものを予測する回帰モデルでは、テスト期間のMAEが約4.22となり、前日価格を使用するベースラインの約3.27を上回りました。

この結果から、**価格予測の精度だけでなく、価格高騰の検知と予測結果の活用方法を評価する重要性**を確認しました。

## 💡 6. 学んだこと・今後の課題

今回のプロジェクトを通じて、**機械学習モデルの精度を高めることだけでなく、分析の目的に合った評価指標を選び、結果をどのように活用するかが重要**だと学びました。

特に、価格予測のMAEが改善しなくても、価格高騰の検知結果を活用することで、別の観点から実用性を評価できることが分かりました。

一方で、予測の誤警報や市場環境の変化、代替調達単価の違いによって結果が変わることも確認しています。

今後は、予測性能の安定性や市場変化への対応を検討するとともに、分析結果の再現性と説明の分かりやすさを改善していきます。
