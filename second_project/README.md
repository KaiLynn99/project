# 📊 第2次チームプロジェクト｜JEPX電力価格予測

## 📌 1. プロジェクト概要

K-MOVEの第2次チームプロジェクトとして、日本の電力市場（JEPX）の価格データを分析し、価格予測に取り組んでいます。

Python・SQLを用いてデータの前処理、探索的データ分析（EDA）、予測誤差の評価を行い、**データ分析を実際の課題解決に役立てること**を目指しています。

| 項目 | 内容 |
|---|---|
| 使用技術 | Python、Pandas、SQL、MySQL、Power BI |
| 分析対象 | 日本の電力市場（JEPX） |
| 評価指標 | MAE（平均絶対誤差） |
| 進捗 | 分析・ベースライン検証を実施中 |

## 🔄 2. テーマ変更の経緯

当初は日本のアニメ作品の評価データを用い、作品の特徴や制作陣・声優との関係を分析していました。

しかし、回帰分析による予測結果を実際の課題解決に結びつけることが難しいと考え、チームで検討した結果、**JEPXの電力価格予測**へ変更しました。

初期の分析資料は、テーマ選定と変更の過程を示す記録として保存しています。

## 🛠 3. 主な分析内容

- **データ前処理：** `merged_30min.csv`の構造確認・整理・SQL検証
- **探索的データ分析：** 時間帯別・月別の価格変動、平日と休日の比較、予備率と価格の関係
- **ベースライン予測：** 前日の価格を利用した予測値と実測値を比較
- **予測評価：** `valid`・`test`データのMAEを算出し、予測誤差を検証
