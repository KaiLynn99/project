# 分類（価格急騰予測）・シン・ヒョンジ

チーム・モダピ ・ JEPX東京エリアの電力卸売価格の急騰予測 ・ 2026-11-16時点

## 概要

「翌日のこの30分枠で電力価格が急騰するか」を予測する分類モデルです。
単純なルール（「前日の同じ時間枠が急騰したら、翌日も急騰すると予測する」）が強力なベースラインであるため、**ルール＋モデル（しきい値0.8）**を最終案として採用しました。
供給予備率を加えたモデルBと組み合わせると、検証期間（2025年9～10月）に発生した急騰152件のうち100件を検知します。ルールのみの場合は82件です。

- **y（正解ラベル）：** `y_spike_rel`。当該30分枠の価格が、前日までの30日間平均価格の1.5倍以上なら1
- **評価指標：** 再現率（Recall）、適合率（Precision）、PR-AUC
- **使用データ：** `D02_전처리&정제 데이터/merged_30min.csv` （チーム共有ドライブ上の実際のフォルダ名を保持）

## 設定

- **特徴量Xから除外した列：** `date`, `slot`, `slot_start`, `split`, `y_price`, `y_spike_rel`, `has_occto`, `lng_yen_per_t_m1`（リークのリスク）、`regime_2026`（学習期間中は常に0）
- **追加した特徴量：** `ratio_lag1d`, `ratio_lag7d`, `ratio_mean7d`, `spike_lag1d`（前日までの情報に基づくため、リークなし）
- **モデル：** LightGBM、`n_estimators=300, learning_rate=0.03, num_leaves=15, min_child_samples=100, reg_lambda=1.0, subsample=0.8, colsample_bytree=0.8, class_weight="balanced", random_state=42`
- **期間：** モデルAは学習2024.4～2025.4／検証2025.5～10。モデルBは学習2025.4～8／検証2025.9～10
- **テスト：** 学習＋検証期間で再学習した後、2025.11～2026.10に**一度だけ**適用

## 実行方法

1. Googleドライブで`kmove 2차 프로젝트`のショートカットを「マイドライブ」に追加します。
2. NotebookをGoogle Colabで開き、上から順に実行します。
3. フォルダの位置が異なる場合は、ステップ0の`BASE`パスを1行だけ変更します。

> **注意：** Notebook内の韓国語のフォルダ名・ファイル名はチーム共有ドライブの実パスです。日本語化によって実行環境との互換性を損なわないよう、パス自体は変更していません。グラフ上の文字列・説明・メッセージは日本語化しています。

## 限界と留意点

- モデルBの検証期間は2か月（急騰152件）と短く、指標にばらつきが生じる可能性があります。
- モデルBは主に夏季（2025.4～8）のデータで学習しています。冬季の性能はテストで検証する必要があります。
- 気象情報には実測値を使い、「完全に正確な天気予報が利用可能」と仮定しています。
- **このパッケージは日本語翻訳版です。** 指標は提供された原本の値を保持していますが、元の統合CSVを用いたモデルの再学習・再評価は実施していません。
