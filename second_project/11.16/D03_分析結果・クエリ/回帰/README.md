# JEPX電力価格の回帰ベースライン（2026-11-16）

## 目的
前日の同時刻における東京エリアの電力価格 `price_tokyo_lag1d` を、翌日の同時刻の価格に対する単純な予測値として使用し、実測価格 `y_price` との平均絶対誤差（MAE）を評価する。**現時点では機械学習の回帰モデルを学習していない。**

## 分析条件
- 元データ：`merged_30min.csv`（45,312行、73列。チームの共有ドライブで保管）
- 検証（Valid）：2025-09-01〜2025-10-31、2,928行、MAE **1.832363**
- テスト（Test）：2025-11-01〜2026-10-31、17,520行、MAE **3.273166**
- 評価対象から除外した行数：0行。検証期間とテスト期間の長さが異なるため、単純比較やハイパーパラメータ調整時には注意が必要。
- 従来の検証期間（2025年5〜10月）のMAE **1.894855** は、**対象期間が異なる分析結果**であり、計算ミスではない。

## 実行方法
Google Colabに `.ipynb` をアップロードし、すべてのセルを上から順に実行する。`merged_30min.csv` が実行環境に存在しない場合、ファイルのアップロード画面が表示される。Notebook内の `results/` と `regression_charts/` は実行時に作成される。

このパッケージに含まれるPNGは、チーム共有用の元の韓国語グラフを基に**文字表記のみを日本語に差し替えたもの**である。Notebookを再実行すると、`regression_charts/` にグラフが生成されるが、レイアウトやファイル名が異なる場合がある。使用するMAEと分析条件は共通である。

**日本語フォントについて：** Notebookは実行環境で使用可能な日本語フォント（Noto Sans CJK JP、IPAexGothicなど）を検出して使用する。該当フォントがない環境では、日本語の文字が正しく表示されない可能性がある。必要に応じて日本語フォントをインストールし、カーネルを再起動すること。

**データ配置について：** ノートブックの相対パス探索は `merged_30min.csv` を基準にしている。`11.13/data/raw/` の元データを直接読み込むコードではない。

## 注意事項
- PR-AUC・PR曲線・価格急騰の重要特徴量を示すグラフは**分類担当者の成果物**であり、本回帰ベースラインの成果物には含めない。
- 回帰モデルを学習していないため、特徴量重要度（Feature Importance）や回帰モデルの性能改善効果を主張しない。
- データを外部公開する前に、元データの再配布条件とチーム内の合意を確認する。テストデータをモデルの選択・調整に使用しない。
